OneButtonPrompt Analysis & Improvement Workflow
================================================

┌─────────────────────────────────────────────────────────────────┐
│                    STEP 1: INITIAL ANALYSIS                     │
└─────────────────────────────────────────────────────────────────┘

    python3 run_full_analysis.py
           │
           ├──> analyze_csv_architecture.py
           │    │
           │    ├─ Scans csvfiles/ directory
           │    ├─ Counts entries per file
           │    ├─ Identifies structure patterns
           │    └─ Outputs: csv_architecture_analysis.json
           │
           └──> analyze_obp_generations.py
                │
                ├─ Generates 1000 test prompts
                ├─ Tracks element frequency
                ├─ Identifies overused items
                └─ Outputs: obp_analysis_results.json

           ↓

    Combined Recommendations
    ├─ HIGH PRIORITY: Overused artists (>2%)
    ├─ HIGH PRIORITY: Imbalanced subjects
    ├─ MEDIUM PRIORITY: Small core files
    └─ LOW PRIORITY: Missing features


┌─────────────────────────────────────────────────────────────────┐
│                  STEP 2: CREATE IMPROVEMENTS                    │
└─────────────────────────────────────────────────────────────────┘

    python3 create_addon_template.py
           │
           ├──> Reads obp_analysis_results.json
           │
           ├──> Creates userfiles/artists_addon_template.csv
           │    └─ 50 alternative artists
           │
           ├──> Creates userfiles/descriptors_addon_template.csv
           │    └─ 40 distinctive descriptors
           │
           └──> Creates userfiles/concepts_addon_template.csv
                └─ 40 abstract concepts

           ↓

    Manual Step: Edit Templates
    ├─ Review suggested entries
    ├─ Add your own entries
    ├─ Remove unwanted entries
    └─ Rename files (remove _template suffix)


┌─────────────────────────────────────────────────────────────────┐
│                   STEP 3: VERIFY IMPROVEMENT                    │
└─────────────────────────────────────────────────────────────────┘

    python3 run_full_analysis.py
           │
           └──> Compare Results
                │
                ├─ Before: Top artist 5.2%
                │  After:  Top artist 1.8%
                │  Result: 65% reduction ✓
                │
                ├─ Before: Subject ratio 9:1
                │  After:  Subject ratio 3:1
                │  Result: 67% improvement ✓
                │
                └─ Overall variety: +300% ✓

        ┌───────────────┴───────────────┐

        │                               │

        │

        │
        └─ Small core files <200?
